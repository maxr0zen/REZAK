# Нижний видеоряд для TikTok

В разделе Twitch у каждого канала есть переключатель **«СДВГ-режим»**. По умолчанию выключен: при включении добавляется фоновый видеоряд без звука, при выключении используется только материал стрима. Настройка фиксируется при создании каждой части или LIVE-окна; изменение во время записи относится к следующим окнам, не меняет уже готовые или поставленные в очередь ролики. Ручные загрузки без привязки к каналу используют глобальную настройку библиотеки. Горизонтальные подборки не получают фон.

Для вертикальных роликов без фонового видео и с найденными вебкой/экраном применяется композиция по референсу `https://www.youtube.com/shorts/1_rb651jSMU`: верхняя панель с вебкой, субтитры между панелями, увеличенный контент снизу. Боковые края контента обрезаются. При устойчивом обнаружении лица внутри контента кроп смещается к нему; иначе используется центр. Это геометрическая эвристика, а не понимание всех важных объектов игры. Просматривайте результат перед публикацией. Логотип и оформление автора референса не копируются.

Новые вертикальные экспорты используют локальную библиотеку `data/backgrounds/library.json`, если `enabled` равно `true`. Горизонтальные подборки не меняются. Интернет во время рендера не используется.

Композиция 720×1280: заголовок начинается на высоте 64 px и показывается первые пять секунд; основной стрим целиком вписывается выше субтитров; нижняя область заполнена отдельным видео без звука. Заголовок накладывается поверх изображения; через пять секунд исчезает только текст. Размер и положение вебки, основного видео, субтитров и нижней панели остаются постоянными. Выбранные вручную области основного стрима сохраняются. Удаляются только края фонового видео, чтобы заполнить нижнюю область.

Библиотека содержит Minecraft Parkour от **Batty's Free Footage**:

- Оригинал: https://www.youtube.com/watch?v=ZCPt78a1eLc
- Лицензия оригинальной публикации 2023 года: Creative Commons Attribution (CC BY 3.0), https://creativecommons.org/licenses/by/3.0/
- Изменения: звук удалён, кадр обрезан для нижней области, при необходимости повторяется.

Текст для указания автора при публикации:

> Фоновый паркур: Batty's Free Footage — Creative Commons - Minecraft Parkour Gameplay, https://www.youtube.com/watch?v=ZCPt78a1eLc. CC BY 3.0: https://creativecommons.org/licenses/by/3.0/. Без звука, кадрирование и повтор.

Сведения об источнике и изменениях также сохраняются в `background_credit` файла `.edit.json` каждой новой копии. При редактировании эти сведения сохраняются.

Для расширения библиотеки добавьте совместимое локальное видео H.264 и запись в `assets`: `file`, `title`, `author`, `source_url`, `license`, `license_url`. Имена файлов — латиница, цифры, `_`, `-`. Путь вне библиотеки и символические ссылки запрещены. Для каждого TikTok файл и начальная позиция выбираются воспроизводимо по источнику и началу эпизода. Ошибочная включённая библиотека выдаёт явную ошибку, а не молча меняет монтаж. Для отключения укажите `enabled: false`.

Библиотека и локальный код `rezak` подключены в Docker только для чтения. Новые контейнеры используют актуальный локальный код; после изменений зависимостей нужно пересобрать `docker compose build app`. Работающие процессы продолжат текущие задачи со своей загруженной версией кода. Уже готовые ролики не переделываются автоматически.
