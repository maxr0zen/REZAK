## Решения и ограничения

Не внедрены Redis/Postgres, UI-заглушка, новая модель или сервер модели. CLI предшествует API. Docker использует кандидат Python 3.11; на хосте проверен Python 3.14, ASR под ними ещё не проверен. Размер превью намеренно небольшой для CPU-проверок. Успешные тесты движка не означают готовность автоматического приложения.
